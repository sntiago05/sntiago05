## About

I'm a software development student focused on **backend development with Java and Spring Boot**. I learn by building projects, reviewing what breaks, and documenting the trade-offs I made.

I'm currently working on REST API design, relational data modeling with PostgreSQL, containerized development with Docker, and software architecture (layered and hexagonal designs). I'm also learning Angular and reading about microservices.

## Mindset

- **Fundamentals before frameworks.** Tools change; the ideas underneath them last longer. I try to understand what a framework is doing for me before I rely on it.
- **Optimal means right for the context.** The best solution is not the most sophisticated one, but the simplest design that meets the requirements, can be maintained, and can evolve. I measure before I optimize.
- **Trade-offs over absolutes.** Every decision costs something. I write down what I chose, what I gave up, and why.
- **Learn by building and breaking.** I ship small projects, review what failed, and record the technical debt openly instead of hiding it.
- **Readable code is a feature.** Clear naming, small units, and tests that explain intent matter as much as the code that works.

## Fundamentals first

I'm not tied to a single technology. I invest in the foundations that transfer between stacks:

- **Programming:** object-oriented design, SOLID principles, data structures and algorithms, complexity analysis
- **Architecture:** layered and hexagonal designs, separation of concerns, dependency inversion
- **Data:** relational modeling, normalization, indexing, transactions, SQL
- **Web and networking:** HTTP, REST semantics, authentication and authorization (JWT), caching basics
- **Systems:** Linux, concurrency basics, containers, and how an application behaves when deployed
- **Quality:** automated testing, code review, and reading other people's code
