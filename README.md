## About Me

Hey! I'm Santiago, a software development student from Colombia. I got into programming because I was curious about what actually happens behind the screen.

I'm currently focused on **backend development with Java and Spring Boot**, while improving my skills in **PostgreSQL, REST APIs, Docker, and software architecture**.

I learn best by building things, breaking them, and figuring out why they broke. Most of the projects you'll find here are part of that process.

**Still learning, still building, and always looking for a better way to do things.**

A backend-oriented e-commerce project built as part of my learning process.

### PharmaLink

A platform designed to centralize the process of medication dispensing and collection between healthcare providers, patients and pharmacies.

The project focuses on integrating different actors into a single platform while managing medication orders, pharmacy availability and inventory.

**Technologies:** Node.js, Express, PostgreSQL, Docker, REST APIs.
